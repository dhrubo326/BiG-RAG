# Bug Fixes - October 31, 2025

## Summary

Fixed critical bugs preventing document stats and evaluation metrics from working correctly after document uploads to BiG-RAG API.

## Issue: Document Stats Show 0 Despite Successful Graph Build

### Problem Description

**User Report:**
- Terminal logs: `INFO:bigrag:Writing graph with 564 nodes, 413 edges`
- API response: `"stats": {"chunks": 0, "entities": 0, "edges": 0, "tokens": 0}`

**Symptoms:**
- Document successfully uploaded and processed
- Knowledge graph built successfully (verified in terminal logs)
- But `/documents/{document_id}` endpoint returned all zeros for stats
- `/documents/{document_id}/entities` returned empty list
- Evaluation endpoints likely affected

### Root Cause Analysis

**Data Structure Mismatch:**

1. **Chunks file** (`kv_store_text_chunks.json`):
```json
{
  "chunk-710e6d96a7830efebf274af94ee904f2": {
    "tokens": 1200,
    "content": "...",
    "chunk_order_index": 0,
    "full_doc_id": "doc-53a0479813a7da9e631fcac2f7c0a80d"  // ← Correct field!
  }
}
```

2. **Buggy code** was checking for **`doc_id`** (doesn't exist):
```python
# ❌ WRONG - line 87 in api/kg_utils.py
if document_id in c_id or c.get("doc_id") == document_id
```

3. **Entity/Edge source_id** contains **chunk IDs**, not document IDs:
```json
{
  "entity-abc123": {
    "entity_name": "Bangladesh",
    "source_id": "chunk-710e6d96a7830efebf274af94ee904f2"  // ← Chunk ID, not doc ID!
  }
}
```

4. **Buggy code** was checking if document_id is substring of source_id:
```python
# ❌ WRONG - line 102, 116 in api/kg_utils.py
if document_id in str(e.get("source_id", ""))
# This fails because:
# - document_id = "doc-53a0479813a7da9e631fcac2f7c0a80d"
# - source_id = "chunk-710e6d96a7830efebf274af94ee904f2"
# - These don't overlap!
```

## Solutions Implemented

### File: [api/kg_utils.py](api/kg_utils.py)

#### 1. Fixed `get_document_stats_from_kg()` (lines 78-137)

**Before:**
```python
# Filter by document ID
doc_chunks = [
    c for c_id, c in chunks.items()
    if document_id in c_id or c.get("doc_id") == document_id  # ❌ Wrong field
]

# Count entities (wrong logic)
doc_entities = [
    e for e_id, e in entities.items()
    if document_id in str(e.get("source_id", ""))  # ❌ source_id has chunk IDs
]
```

**After:**
```python
# 1. Get all chunk IDs for this document
doc_chunks = [
    (c_id, c) for c_id, c in chunks.items()
    if c.get("full_doc_id") == document_id  # ✅ Correct field name
]
doc_chunk_ids = set(c_id for c_id, _ in doc_chunks)

# 2. Count entities that reference our chunk IDs
doc_entities = []
for e_id, e in entities.items():
    source_id_str = str(e.get("source_id", ""))
    source_ids = source_id_str.split(GRAPH_FIELD_SEP) if GRAPH_FIELD_SEP in source_id_str else [source_id_str]

    # Check if any source_id matches our document's chunks
    if any(sid in doc_chunk_ids for sid in source_ids):
        doc_entities.append(e)
```

**Key Changes:**
- ✅ Use `full_doc_id` field instead of non-existent `doc_id`
- ✅ First collect chunk IDs belonging to document
- ✅ Then find entities/edges that reference those chunk IDs
- ✅ Handle multiple source IDs separated by `GRAPH_FIELD_SEP`

#### 2. Fixed `get_document_entities()` (lines 142-201)

**Before:**
```python
doc_entities = [
    {
        "name": e.get("entity_name"),
        "type": e.get("entity_type"),
        "weight": e.get("weight", 0)
    }
    for e_id, e in entities.items()
    if document_id in str(e.get("source_id", ""))  # ❌ Wrong logic
]
```

**After:**
```python
# 1. Load chunks and get chunk IDs for this document
doc_chunk_ids = set(
    c_id for c_id, c in chunks.items()
    if c.get("full_doc_id") == document_id
)

# 2. Filter entities by chunk IDs
doc_entities = []
for e_id, e in entities.items():
    source_id_str = str(e.get("source_id", ""))
    source_ids = source_id_str.split(GRAPH_FIELD_SEP) if GRAPH_FIELD_SEP in source_id_str else [source_id_str]

    if any(sid in doc_chunk_ids for sid in source_ids):
        doc_entities.append({
            "name": e.get("entity_name"),
            "type": e.get("entity_type"),
            "weight": e.get("weight", 0)
        })
```

#### 3. Fixed `find_related_documents()` (lines 204-308)

**Before:**
```python
# Get this document's entities (wrong)
doc_entities = set([
    e.get("entity_name")
    for e_id, e in entities.items()
    if document_id in str(e.get("source_id", ""))  # ❌ Doesn't work
])

# Map source_ids to documents (wrong)
for source_id in source_ids:
    if not source_id or source_id == document_id:  # ❌ source_id is chunk ID
        continue
    doc_scores[source_id] += 1  # ❌ Counting chunks, not documents
```

**After:**
```python
# 1. Build chunk_id -> document_id mapping
chunk_to_doc = {
    c_id: c.get("full_doc_id")
    for c_id, c in chunks.items()
    if c.get("full_doc_id")
}

# 2. Get chunk IDs for this document
doc_chunk_ids = set(
    c_id for c_id, c in chunks.items()
    if c.get("full_doc_id") == document_id
)

# 3. Get this document's entities (using chunk IDs)
doc_entities = set()
for e_id, e in entities.items():
    source_id_str = str(e.get("source_id", ""))
    source_ids = source_id_str.split(GRAPH_FIELD_SEP) if GRAPH_FIELD_SEP in source_id_str else [source_id_str]
    if any(sid in doc_chunk_ids for sid in source_ids):
        doc_entities.add(e.get("entity_name"))

# 4. Find documents with overlapping entities
for chunk_id in source_ids:
    if not chunk_id or chunk_id in doc_chunk_ids:
        continue

    # Map chunk_id to document_id
    related_doc_id = chunk_to_doc.get(chunk_id)
    if not related_doc_id:
        continue

    doc_scores[related_doc_id] += 1  # ✅ Now counting documents, not chunks
```

## Lessons Learned

1. **Always check actual data structure** - Don't assume field names
2. **Understand ID relationships** - Chunks → Entities/Edges via chunk IDs
3. **Substring matching is fragile** - Use exact equality checks
4. **Log terminal output vs API output** - Discrepancies reveal bugs
5. **Test with real data** - Edge cases like empty results matter
